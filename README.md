# ADOFAI Mod Helper (얼불춤 모드 도우미)

**한국어** | [English](README.en.md)

얼불춤(A Dance of Fire and Ice) 모드를 처음 쓰는 사람을 위한 Windows 프로그램입니다.
Unity Mod Manager(UMM) 설치부터 모드 설치·업데이트·켜기/끄기까지 버튼으로 끝냅니다.

- **exe 하나**: 설치 없이 더블클릭으로 실행
- **UMM 자동 설치**: 공식 배포처에서 최신 UMM을 받아 공식 설치기와 같은 방식으로 설치
- **모드 원클릭 설치**: 목록에서 고르면 최신 버전을 받아 설치, 필요한 라이브러리(JALib 등)도 자동으로
- **관리**: 켜기/끄기, 삭제(휴지통), 일괄 업데이트, UMM 제거, 게임 업데이트 감지
- **잘못된 설치 자동 정리**: `Mods/Mods/…`처럼 잘못 넣은 모드, 겹친 모드, 압축 안 푼 zip을 버튼 하나로
- **진단 정보 복사**: 문의할 때 붙여넣을 상태 요약
- 한국어 / English

## 필요한 것

- Windows 10 (1903 이상) 또는 Windows 11
- Steam판 얼불춤 3.x
- 인터넷 연결 (UMM과 모드를 받을 때)

.NET 같은 것을 따로 설치할 필요는 없습니다. Windows에 기본으로 들어 있는 .NET Framework 4.8을 씁니다.

## 설치하는 법

1. **[최신 릴리스](https://github.com/newmouse11/adofai-mod-helper/releases/latest)에서 `AdofaiModHelper.exe`를 받습니다.**
   바탕화면 같은 아무 폴더에 두면 됩니다. 게임 폴더 안에 둘 필요는 없습니다.
2. **실행합니다.** 파란 "Windows의 PC 보호" 창이 뜨면 **추가 정보 → 실행**을 누르세요 ([왜 뜨나요?](#windows의-pc-보호-파란-창이-떠요)).
3. **첫 실행 마법사를 따라갑니다.**
   1. **게임 찾기**: Steam에 설치된 얼불춤을 자동으로 찾습니다. 못 찾으면 **[직접 찾기]**를 눌러 `A Dance of Fire and Ice.exe`를 고르세요.
   2. **UMM 설치**: **[UMM 설치]**를 누르면 받아서 설치까지 끝납니다. 이미 설치돼 있으면 **[다음]**.
   3. **모드 고르기**: 원하는 모드를 체크하고 **[선택한 모드 설치]**. 나중에 해도 되면 **[건너뛰기]**.
4. **게임을 실행하고 `Ctrl + F10`을 누르면** UMM 모드 메뉴가 열립니다.

## 자주 묻는 질문

### "Windows의 PC 보호" 파란 창이 떠요
코드 서명(유료 인증서)이 없는 프로그램이라 Windows가 "처음 보는 파일"이라고 알리는 것입니다. 악성 판정은 아닙니다.
**추가 정보 → 실행**을 누르면 됩니다. 걱정되면 릴리스의 `SHA256SUMS.txt`와 값이 같은지 확인하세요.
```bat
certutil -hashfile AdofaiModHelper.exe SHA256
```

### 게임을 못 찾는다고 나와요
마법사 1단계나 위쪽 **[변경]**에서 `A Dance of Fire and Ice.exe`를 직접 고르세요.
위치를 모르겠으면 Steam에서 얼불춤 우클릭 → **관리 → 로컬 파일 보기**로 열리는 폴더입니다.

### "게임 폴더에 파일을 쓸 권한이 없어요"라고 나와요
게임이 `C:\Program Files` 아래처럼 보호된 폴더에 있으면 생길 수 있습니다. 창에서 **[관리자로 다시 실행]**을 누르세요.

### 게임에서 `Ctrl + F10`을 눌러도 메뉴가 안 떠요
1. 노트북이면 `Fn` 키를 같이 눌러 보세요 (`Ctrl + Fn + F10`).
2. 도구 위쪽에 UMM이 **설치됨**으로 나오는지 확인하세요. **손상됨**이면 **[복구]**를 누르세요.
3. 그래도 안 되면 아래 [문의하기](#문의하기)를 참고하세요.

### 모드를 넣었는데 게임에서 안 보여요
얼불춤은 `Mods` 폴더 **바로 아래** 폴더만 읽습니다. `Mods/Mods/모드이름`처럼 한 번 더 들어가 있거나, zip을 풀지 않고 넣으면 무시됩니다.
도구를 열면 노란 알림 줄에 "잘못 설치된 모드가 N개 있어요"가 나옵니다. **[고치기]**를 누르면 제자리로 옮겨 줍니다. 같은 모드가 두 개면 버전이 높은 쪽만 남기고 나머지는 휴지통으로 보냅니다.

### 게임 업데이트 후 게임이 안 켜져요
게임이 업데이트되면 도구가 알려 줍니다. 아래 순서대로 해 보세요.
1. 알림 줄의 **[업데이트 확인]**: 모드가 새 버전에 맞춰 업데이트됐을 수 있습니다.
2. 그래도 안 되면 **[모드 전부 끄기]**: 켜지면 하나씩 다시 켜서 문제 모드를 찾으세요.
3. 그래도 안 되면 아래쪽 **[UMM 제거]**: 게임이 모드 없는 원래 상태로 돌아갑니다.

### 이미 있는 모드를 업데이트하면 설정은 어떻게 되나요?
이미 설치된 모드를 다시 받으면(업데이트·**[모두 업데이트]** 포함) 확인창이 먼저 뜹니다.
- **[설정 유지하고 설치]**: 모드 파일만 새 버전으로 덮어쓰고, 쓰던 설정 파일은 그대로 둡니다. 보통은 이걸 고르면 됩니다.
- **[새로 설치]**: 기존 폴더를 휴지통으로 보내고 처음 상태로 설치합니다. 설정이 꼬였거나 업데이트 후 이상할 때 쓰세요.
- **[취소]**: 아무것도 바꾸지 않습니다.

어느 쪽이든 켜기/끄기 상태는 그대로 유지됩니다.

### 모드를 끄면 어떻게 되나요?
그 모드의 dll 파일 이름이 `이름.dll.disabled`로 바뀌어 UMM이 불러오지 않습니다. 다시 켜면 원래 이름으로 돌아오고, 모드 설정은 그대로입니다.
라이브러리(JALib 등)를 끄면 그걸 쓰는 모드도 같이 동작하지 않으니, 도구가 어떤 모드가 영향을 받는지 알려 줍니다.

### 목록에 없는 모드를 쓰고 싶어요
모드 zip을 풀어서 `Info.json`이 들어 있는 폴더째로 게임의 `Mods` 폴더에 넣으세요. zip을 그대로 넣었다면 도구의 **[고치기]**가 풀어서 설치해 줍니다.
설치한 뒤에는 이 도구에서 켜기/끄기·삭제를 할 수 있습니다. 목록에 추가하고 싶은 모드는 [Issues](https://github.com/newmouse11/adofai-mod-helper/issues)에 알려 주세요.

### "MelonLoader(또는 BepInEx)가 함께 설치돼 있어요"라고 나와요
모드 로더를 두 개 같이 쓰면 충돌할 수 있습니다. 이 도구는 UMM용입니다. 하나만 쓰는 것을 권장합니다.

### "GitHub 요청 한도에 걸렸어요"라고 나와요
GitHub는 로그인하지 않은 요청을 1시간에 60번까지만 받습니다. 안내된 시각 이후에 다시 시도하세요. 도구는 15분 안에 확인한 결과를 다시 쓰기 때문에 평소에는 거의 걸리지 않습니다.

### "게임 경로에 영문이 아닌 글자가 있어요" 경고가 떠요
UMM은 영문이 아닌 글자가 든 경로에서 문제가 날 수 있습니다. 동작하면 그대로 써도 되고, 안 되면 Steam 라이브러리를 영문 경로(예: `D:\SteamLibrary`)로 옮기세요.

### 모드를 완전히 없애고 원래 게임으로 돌리고 싶어요
아래쪽 **[UMM 제거]**를 누르세요. UMM 파일만 휴지통으로 가고, 모드 폴더와 켜기/끄기 설정은 남습니다. 다시 설치하면 그대로 돌아옵니다.
모드까지 지우려면 게임 폴더의 `Mods` 폴더도 지우세요. 세이브 데이터는 건드리지 않습니다.

### 마법사를 처음부터 다시 보고 싶어요
도구를 끄고 `%LocalAppData%\AdofaiModHelper` 폴더를 지운 뒤 다시 실행하세요. 설정과 로그만 지워지고 게임은 그대로입니다.

### 문의하기
아래쪽 **[진단 정보 복사]**를 누른 뒤 [Issues](https://github.com/newmouse11/adofai-mod-helper/issues)나 디스코드 문의에 붙여넣어 주세요.
게임 경로, UMM 상태, 모드 목록, 최근 로그가 들어 있어서 원인을 찾기 쉽습니다. 비밀번호 같은 정보는 들어가지 않지만, 경로에 Windows 사용자 이름이 보일 수 있으니 붙여넣기 전에 한 번 확인하세요.

## 모드 목록 관리 (`catalog/mods.json`)

도구는 실행할 때 이 저장소의 `catalog/mods.json`을 읽습니다. **이 파일만 고쳐서 push하면 도구를 다시 배포하지 않아도 목록이 바뀝니다.**
(인터넷이 안 되거나 파일을 못 받으면 exe에 내장된 사본을 씁니다.)

```jsonc
{
  "id": "TimingShow",                    // 모드 Info.json의 Id와 같아야 설치 여부·업데이트를 인식
  "name": "TimingShow",                  // 화면에 보일 이름
  "author": "SleepingCui",
  "repo": "SleepingCui/TimingShow",      // GitHub 소유자/저장소
  "asset": "^TimingShow\\.zip$",         // 릴리스 파일 중 UMM용 zip을 고르는 정규식
  "prerelease": false,                   // 정식 릴리스가 없는 저장소(JALib)만 true
  "library": false,                      // true면 마법사 목록에 숨기고 필요할 때만 자동 설치
  "requires": ["JALib"],                 // 함께 설치할 모드 Id
  "description": { "ko": "…", "en": "…" }
}
```

- MelonLoader 전용 모드는 넣지 마세요 (이 도구는 UMM만 지원).
- 항목을 추가했으면 `dotnet run --project tests/SelfTest -c Release -- --online`으로 **실제로 받아서 Id가 맞는지** 확인할 수 있습니다.

## 개발

필요: Windows + .NET SDK (10.0.402로 검증, 빌드 대상은 .NET Framework 4.8)

```bash
dotnet build src/AdofaiModHelper -c Release
```

결과물: `src/AdofaiModHelper/bin/Release/net48/AdofaiModHelper.exe` (이 파일 하나만 배포)

```bash
dotnet run --project tests/SelfTest -c Release
```

자체 검사: 가짜 게임 폴더에서 UMM 설치·진단·제거, 모드 설치·켜기/끄기·중첩 정리 등을 확인합니다. `-- --online`을 붙이면 실제 UMM과 목록의 모든 모드를 받아 설치까지 확인합니다.

릴리스: `<Version>`을 올리고 `v버전` 태그를 push하면 GitHub Actions가 빌드·자체 검사 후 exe와 `SHA256SUMS.txt`로 릴리스를 만듭니다.

| 위치 | 내용 |
|---|---|
| `src/AdofaiModHelper/Core/` | 화면과 무관한 로직 (게임 탐지, UMM 설치, 모드 관리, 목록, 진단) |
| `src/AdofaiModHelper/MainWindow.xaml(.cs)` | 마법사와 메인 화면 |
| `src/AdofaiModHelper/Theme.xaml` | 색·글꼴·컨트롤 스타일 |
| `src/AdofaiModHelper/Strings.*.xaml` | 한/영 문구 |
| `catalog/mods.json` | 원클릭 설치 모드 목록 |

## 동작 방식 (참고)

UMM 공식 설치기(`UnityModManagerApp/Form.cs`)의 DoorstopProxy 설치를 그대로 재현합니다.

- `게임\winhttp.dll` ← UMM zip의 `winhttp_x64.dll`(또는 x86) / `게임\doorstop_config.ini`
- `게임\A Dance of Fire and Ice_Data\Managed\UnityModManager\` ← `UnityModManager.dll`, `0Harmony.dll`, `dnlib.dll`, `UnityModManager.xml`, `Config.xml`
- 모드를 끄면 그 모드의 dll(Info.json의 `AssemblyName`)을 `이름.dll.disabled`로 바꾸고, UMM의 `Params.xml`도 꺼짐으로 맞춥니다. 켜면 원래대로 되돌립니다. 꺼 둔 모드는 업데이트해도 꺼진 채로 유지됩니다.
- 지우는 것은 전부 휴지통으로 보냅니다. 세이브 폴더(`User`)는 건드리지 않습니다.
